Frequently asked questions
Comment réinitialiser complètement ma préparation ?
Cliquez sur le bouton ci-dessous pour repartir de zéro. Cela supprimera toutes vos statistiques et votre progression, tout en conservant vos paramètres personnels.

Comment fonctionnent les rappels quotidiens ?
Les rappels quotidiens sont de courtes notifications qui vous aident à maintenir un rythme d’entraînement régulier. Une fois activés, vous recevez une notification lorsque votre test quotidien est prêt.

Utilisateurs iPhone / iPad : pour recevoir les rappels quotidiens, vous devez utiliser Safari, appuyer sur l’icône Partager, choisir « Ajouter à l’écran d’accueil », puis ouvrir CivicLearn depuis l’écran d’accueil avant d’activer l’interrupteur ci-dessous.

Les questions du test sont-elles officielles ?
Non. Les questions proposées sur CivicLearn sont des simulations pédagogiques conçues pour refléter la structure, le niveau de difficulté et les thèmes clés du test luxembourgeois Vivre-Ensemble.

Il ne s’agit pas de questions officielles et elles ne proviennent d’aucune base de données gouvernementale. Les questions officielles ne sont pas rendues publiques par les autorités luxembourgeoises.
Que représentent les questions affichées sur le tableau de bord ?
Les questions affichées sur le tableau de bord font partie d’un mode d’entraînement séquentiel qui regroupe l’ensemble des questions du questionnaire luxembourgeois, présentées une par une dans un ordre fixe.

Vous pouvez passer à la question suivante ou revenir à la précédente, ce qui permet de sauter certaines questions et d’y revenir plus tard. C’est le seul mode d’entraînement dans lequel les questions peuvent être ignorées temporairement.

Votre progression est enregistrée automatiquement : si vous quittez la page ou la rechargez, le tableau de bord s’ouvrira sur la dernière question consultée.
À quoi sert la fonctionnalité « Ma liste » ?
Sur chaque question, une petite étoile permet d’ajouter la question à votre liste personnelle de révision. En cliquant sur cette étoile, la question est enregistrée dans « Ma liste ».

Cette fonctionnalité vous permet de mettre de côté les questions importantes ou difficiles afin de les revoir plus tard, à votre rythme, et de cibler plus efficacement vos révisions.
Quelle est la différence entre les modes de test ?
CivicLearn propose plusieurs modes d’entraînement adaptés à différents besoins :
  • Simulation d’examen : Reproduit le format officiel du test (plusieurs questions, chronomètre, résultats à la fin).
  • Test rapide : 5 questions aléatoires, sans limite de temps, correction immédiate.
  • Test par thème : Vous choisissez un ou plusieurs thèmes. Ce mode est adaptatif : les questions se répètent jusqu’à ce qu’elles soient toutes maîtrisées.
  • Pièges fréquents : Entraînement ciblé sur les erreurs les plus courantes, sans chronomètre.
Comment fonctionne le mode progressif ?
Le mode progressif ne s’arrête pas après un nombre fixe de questions. Les questions mal répondues sont automatiquement reposées jusqu’à ce qu’elles soient toutes maîtrisées. Lorsqu’il n’en reste plus, le message suivant s’affiche : « Tout est maîtrisé ».
Pourquoi certains tests affichent-ils les boutons « Recommencer » ou « Revoir les erreurs » ?
Ces boutons apparaissent uniquement dans les tests non progressifs (comme la simulation). Le test se termine une fois toutes les questions répondues, puis vous pouvez revoir vos erreurs ou recommencer une nouvelle tentative.
Quel mode utiliser pour se préparer efficacement ?
Pour une préparation complète :
  • Commencez par le Test par thème afin de consolider vos connaissances par thème.
  • Utilisez le Test rapide pour des révisions quotidiennes légères.
  • Terminez par une Simulation d’examen pour évaluer votre niveau dans des conditions proches du réel.
Pourquoi la voix du mode « Assistance à la lecture » semble-t-elle étrangère ?
CivicLearn utilise le système de synthèse vocale intégré à votre navigateur pour lire les questions à voix haute.

Si votre appareil ne dispose pas d’une voix de bonne qualité pour la langue sélectionnée (français, allemand ou luxembourgeois), le navigateur peut utiliser une voix générique ou avec un accent différent.

Pour améliorer la prononciation, installez des voix supplémentaires dans les paramètres d’accessibilité ou de langue de votre appareil, puis rechargez la page.
Comment est notée la simulation du test Vivre-Ensemble ?
La simulation CivicLearn reproduit fidèlement le format officiel du test luxembourgeois Vivre-Ensemble.

Chaque simulation comporte 40 questions, réparties exactement comme lors du test officiel :
  • 10 questions sur l’histoire du Luxembourg
  • 10 questions sur les droits fondamentaux
  • 20 questions sur les institutions

Pour réussir, vous devez obtenir au moins 28 réponses correctes sur 40.

Vous disposez d’une heure pour répondre à l’ensemble des questions. Cette limite de temps est appliquée afin de reproduire les conditions réelles du test officiel.

Toutes les questions ont le même poids : il n’y a ni pénalité pour les mauvaises réponses, ni obligation de réussir un thème spécifique à 100 %.
Qu’est-ce que la section « Pièges fréquents » ?
Cette section regroupe les questions auxquelles les utilisateurs répondent le plus souvent incorrectement. Elle vous aide à cibler vos points faibles et à vous préparer plus efficacement avant de tenter une simulation complète.
Puis-je utiliser CivicLearn sur mon téléphone ?
Oui. CivicLearn est une application web optimisée pour les ordinateurs, tablettes et smartphones. Vous pouvez l’ajouter à votre écran d’accueil pour un accès rapide.
Ma progression est-elle enregistrée automatiquement ?
Oui. Vos résultats et statistiques sont enregistrés automatiquement et synchronisés dans le cloud. Vous pouvez poursuivre votre entraînement sur un autre appareil en vous connectant simplement avec la même adresse e-mail.
Puis-je étudier hors ligne ?
Oui. Une fois les pages chargées, la plupart des fonctionnalités (tests, cartes mémoire, guide) restent accessibles sans connexion Internet, à l’exception de l’envoi du formulaire de contact.
Comment fonctionne l’accès Premium ?
L’accès Premium est un achat unique, sans limite de durée. Une fois le paiement confirmé par Stripe, votre compte est activé immédiatement et vous bénéficiez d’un accès à vie, sans renouvellement automatique.
Puis-je obtenir un reçu ?
Les paiements sont traités par Stripe, qui vous envoie automatiquement un e-mail de confirmation après l’achat. Cet e-mail fait office de reçu officiel ; nous n’émettons pas de factures PDF séparées.
Puis-je utiliser mon compte sur plusieurs appareils ?
Oui. Votre progression, votre historique et vos questions sauvegardées sont synchronisés automatiquement entre tous vos appareils. Connectez-vous simplement avec la même adresse e-mail et vos données seront disponibles immédiatement.
Comment signaler une erreur ou une faute ?
Ouvrez le formulaire de contact ci-dessous et précisez la question concernée. Notre équipe examinera votre signalement et mettra à jour la base de données si nécessaire.
